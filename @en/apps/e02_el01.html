Track character-count changes in Visual Studio Code

Edit Log helps you keep a record of your writing activity in Visual Studio Code.
It records the number of characters added and deleted in the active file, along with the resulting total, grouped by date.
A dedicated view appears at the bottom of the Explorer.
The top of the view shows the name of the folder containing the file and the total character count for files in that folder.
Use the checklist icon to choose which files are included in the folder total.
Use the ellipsis menu in the title area to export or import your records.
